## 1 · One-page architecture & risk waterfall

```
  Institutional desks (searchers / MMs) ── single-slot Jito bundles ──► Noviscia CCP
        │  borrow collateralised USDC (24h debt window, 2h grace)
        ▼
  α-sleeve credit vault ──► netting-engine host (credit-line + netting) ──► venues
        │
        ▼  toll: 90% → LP NAV (nv-usdc-vault omni-pool), 10% → treasury
        ▼
  Loss waterfall (simulated numbering at the $10M reference pool):
        L1 desk collateral → L2 committed LoC (25% haircut) →
        L3 protocol reserves (DIF) → L4 junior LP (30%) → L5 senior LP (70%)
```

Everything on-chain (post-consolidation): 4 clusters — clearing/netting
(`netting-engine`), cap/gate + JIT (`noviscia-capacity`), vault/tranche
(`nv-usdc-vault`), governance frozen C4. The waterfall layers are enforced by
the vault program (docs/INSOLVENCY_POLICY.md L1–L5); the figures here are the
**executable numeric twin** of that ordering.

## 5 · Validation plan (what must be measured before "live")

The checklist's second block cannot be satisfied on paper. This is the plan:

1. **Geyser probe** — run `services/grpc-pipeline` yellowstone subscriber
   against devnet for 7 days; collect p50/p95/p99 latency, uptime, disconnect
   rate, dropped-message rate; publish a probe report.
2. **Jito telemetry** — devnet submissions via `jito.ts`, record eligible%,
   submitted/landed/reverted, tip paid per landed bundle; non-Jito detection
   via `ability.ts` guard + devnet proof that allocation pauses.
3. **Atomicity test** — devnet script: send a bundle with a failing repay,
   assert vault + credit-vault balances byte-identical after. Convert S9 from
   `simulated` to `testnet-observed`.
4. **Capacity/liquidity drills** — sandbox-hub: N simultaneous desk draws,
   a withdraw run, a reserve freeze, and circuit-breaker timing; then repeat
   under live devnet.
5. **E2E settlement timing** — measure pull→repay→settle clock time and the
   24h+2h window behavior on devnet.

Each probe flips `pending → testnet-measured` in `assumptions.ts` and adds a
row to §2. Nothing is upgraded from simulated/live by intent — only by
evidence.
